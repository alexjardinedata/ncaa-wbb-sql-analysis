SQL queries
01
Top 10 scorers
Ranks players by total season points using ORDER BY and LIMIT.
SELECT PLAYER_NAME, TEAM_NAME, POINTS FROM wbb_stats ORDER BY POINTS DESC LIMIT 10;
SELECT ORDER BY LIMIT
02
Conference scoring averages
Parses conference name from a compound Team field using SUBSTR and INSTR, then aggregates by conference.
SELECT SUBSTR(Team, INSTR(Team,'(')+1, INSTR(Team,')')-INSTR(Team,'(')-1) AS conference, COUNT(*) AS players, ROUND(AVG(POINTS), 1) AS avg_pts FROM wbb_stats GROUP BY conference ORDER BY avg_pts DESC;
GROUP BY AVG / COUNT SUBSTR / INSTR
03
All-around leaders
Builds a composite metric combining points, rebounds, and assists to surface well-rounded contributors beyond scoring.
SELECT PLAYER_NAME, TEAM_NAME, POINTS, TOTAL_REBOUNDS, ASSISTS, ROUND(POINTS + TOTAL_REBOUNDS + ASSISTS, 1) AS all_around_score FROM wbb_stats WHERE GAMES >= 20 ORDER BY all_around_score DESC LIMIT 15;
Computed cols WHERE filter ROUND
04
Shooting efficiency by team
Compares FG%, 3PT%, and FT% averages across teams, filtered to players with meaningful sample sizes.
SELECT TEAM_NAME, ROUND(AVG(FIELD_GOAL_PERCENTAGE), 1) AS avg_fg_pct, ROUND(AVG(THREE_POINT_PERCENTAGE), 1) AS avg_3pt_pct, ROUND(AVG(FREE_THROW_PERCENTAGE), 1) AS avg_ft_pct FROM wbb_stats WHERE GAMES >= 15 GROUP BY TEAM_NAME ORDER BY avg_fg_pct DESC;
AVG on rates GROUP BY WHERE
05
Above-average scorers
Uses a subquery to dynamically calculate the season average and filter to players who exceeded it.
SELECT PLAYER_NAME, TEAM_NAME, POINTS FROM wbb_stats WHERE POINTS > ( SELECT AVG(POINTS) FROM wbb_stats WHERE GAMES >= 15 ) ORDER BY POINTS DESC;
Subquery WHERE compare AVG
Dataset

Data sourced from pineconedata/ncaa-basketball-stats on GitHub — individual player statistics for the full 2023–24 NCAA Division I women's basketball season.

The player_data_clean.xlsx file was exported to CSV, imported into DB Browser for SQLite, and queried directly. No additional preprocessing was performed beyond the original dataset's cleaning steps.
